# Принципы программы FTP 340

## Цель

Стратегическая цель программы фиксирована: FTP 340 Вт к 6 июня 2027 года.
Текущий FTP показывается как подтверждённый только после внесения результата теста.

## Принципы работы с планом

1. Каждая сессия имеет цель: пороговая работа, аэробная мощность, выносливость, силовая подготовка или восстановление.
2. Мощность и длительность остаются в рамках утверждённой тренировки.
3. Изменения применяются только к будущим датам и требуют подтверждения спортсмена.
4. Выполненные тренировки сохраняются как факты и не переписываются при новой версии плана.
5. Пропуск не компенсируется дополнительной тренировкой без отдельной оценки.
6. Публичная страница содержит только программу, её версию, подтверждённые тесты и отметки выполненных сессий.

## Версии и синхронизация

PostgreSQL TriCoach хранит утверждённую версию программы и историю решений. GitHub хранит историю опубликованных версий сайта. GitHub Pages показывает последнюю проверенную версию календаря. Неподтверждённые предложения остаются приватными в TriCoach и не попадают на сайт.
